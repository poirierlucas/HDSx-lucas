# Dependencies

- **R:** `readr` for CSV import, `dplyr` for filtering and grouped summaries,
  and `knitr` for HTML tables. Quarto renders `polyglot-parity.qmd` to HTML.
- **Python:** `pandas` for CSV import and grouped summaries. `pathlib` and
  `sys` are Python standard-library modules used to locate and import the
  submission helper.
